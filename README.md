# 100 Days of Code in C

**Status: Complete — Day 100 of 100**

This repository contains 150 standalone C solutions based on the [official question bank](https://maitysoumik.github.io/basic-coding-with-c/questions2.json). Each solution begins with its full question statement.

| Days | Questions | Solutions per day |
|---|---|---:|
| Day 1–50 | Q1–Q100 | 2 |
| Day 51–100 | Q101–Q150 | 1 |

Every day folder is named `Day N`. Solution filenames use `Q<number> (Category).c`; the slash in the official `Loops without Arrays/Strings` category is replaced with a hyphen because `/` is not valid in a Windows filename.

Compile a solution with a C11 compiler:

```text
gcc -std=c11 -Wall -Wextra -pedantic "Day 1\Q1 (User Inputs, Operations & Output).c" -o solution
```
